# スケジュール機能 要件定義書

- 作成日: 2026-10-01
- 更新日: 2026-10-02(T-017 議題の追加を反映)
- ステータス: 実装完了・運用中

本書は T-017 の起票に伴い新規作成した最小限の As-Built 仕様書。既存実装の全容ではなく、スケジュールの項目と議題の仕様を記載する。

## 1. 背景・目的

社内 AI 勉強会の開催予定を N Portal 上で共有し、参加者が日時・場所・予定内容を事前に確認できるようにする。

## 2. 機能概要

- スケジュール一覧ページ(`/schedule`)で、開催日が当日以降の回を「今後の予定」、過去の回を「開催済みの回」として表示する。
- トップページに、開催日が当日以降で最も近い回を「次回の会議」として表示する。
- 議題ページ(`/schedule/{id}`)で、回ごとの議題を表示する(§4)。
- スケジュールの作成・編集・削除は管理画面(`/admin/schedule`)で行う。

## 3. スケジュールの項目

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 開催日・開催時間 | 必須 | |

## 4. 議題

- 前後の空白を除去して保存する。空の場合は未設定として扱う。保存時に Markdown を HTML へ変換し、原文と併せて保持する。
- 議題は、回ごとの単独ページ(`/schedule/{id}`。id はスケジュールの ID)で表示する。会議中に別のウィンドウで開いて画面共有する使い方を想定する。
- 議題ページには、会議のタイトル・開催日時・開催場所・トピックと議題の本文を表示し、「一覧へ戻る」を置く。
- 本文は Markdown を変換し、議事録と同じ見た目で表示する。本文に書かれた生の HTML は無効化する。
- スケジュール一覧ページの各回カード(今後の予定・開催済みの回)とトップページの次回の会議に「議題を見る」ボタンを置く。位置は既存のボタン列の、チャットのボタンの左。押すと議題ページへ移動する。
- 議題が未設定の回には、「議題を見る」ボタンを表示しない。議題ページを直接開いた場合は「議題はまだありません。」を表示する。存在しない回の議題ページは 404 とする。

### 対象外

- 議題のモーダル表示・カード内での展開表示
- チャット画面・管理画面のスケジュール一覧での議題表示
- 議題の議事録への連携

## ボタンの並び

- 各回カードのボタン群は、カードの右側に横並びになる幅(1024px 以上)では並びを反転し、先頭のボタンを常に右端に置く。先頭は、今後の予定では「会議に参加する」(無ければ「議題を見る」、それも無ければ「チャットを開く」)、開催済みの回では「議事録を見る」(同様に、無ければ次のボタン)。
- それ未満の幅では、ボタン群は本文の下に左寄せで並び、先頭のボタンが左端になる。
- スケジュールが 1 件も無い場合は「スケジュールはまだありません。」を表示する。
