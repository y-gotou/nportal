本書は T-017 の起票に伴い新規作成した最小限の As-Built 仕様書。既存実装の全容ではなく、スケジュールの項目と議題の仕様を記載する。

## 1. 背景・目的

社内 AI 勉強会の開催予定を N Portal 上で共有し、参加者が日時・場所・予定内容を事前に確認できるようにする。

## 2. 機能概要

- スケジュール一覧ページ(`/schedule`)で、開催日が当日以降の回を「今後の予定」、過去の回を「開催済みの回」として表示する。
- トップページに、開催日が当日以降で最も近い回を「次回の会議」として表示する。
- スケジュールの作成・編集・削除は管理画面(`/admin/schedule`)で行う。

## 3. スケジュールの項目

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 開催日・開催時間 | 必須 | |
| タイトル | 必須 | |
| トピック | 任意 | カンマ区切りで入力し、タグとして表示する |
| 議題 | 任意 | 会議の予定内容を記述する複数行テキスト(§4) |
| 開催場所 | 任意 | |
| 会議URL | 任意 | |

## 4. 議題

- 前後の空白を除去して保存する。空の場合は未設定として扱う。
- 表示箇所は、スケジュール一覧ページの各回カード(今後の予定・開催済みの回)と、トップページの次回の会議。
- 展開式で表示する。「議題」を押すとその場で開閉し、初期状態は閉じている。
- 本文は改行を保持したプレーンテキストとして表示する。HTML・Markdown は解釈しない。
- 議題が未設定の回には、開閉要素を表示しない。

### 対象外

- 議題の別ページ表示・モーダル表示
- チャット画面・管理画面のスケジュール一覧での議題表示
- 議題の議事録への連携
