# リンク動作要件

## 外部リンク

- 現在のページとオリジン（scheme・host・port）が異なる HTTP(S) URL を外部リンクとする。
- 外部リンクは新規タブで開く。
- 外部リンクには `rel="noopener noreferrer"` を付与する。既存の `rel` 値がある場合はそれを保持する。
- 外部リンクの表示文言、アイコン、スタイルは変更しない。
- 通常のページ要素に加え、非同期で追加されるリンクと Markdown から生成されるリンクにも同じ規則を適用する。

## 対象外

- 現在のページと同一オリジンの URL には、外部リンク用の動作を自動適用しない。
- `mailto:` など HTTP(S) 以外の URL には、外部リンク用の動作を自動適用しない。
