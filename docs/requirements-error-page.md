# エラーページ要件

## 表示する場合

- 存在しない URL を開いた場合と、ページの表示に必要なデータを取得できなかった場合に、日本語のエラーページを表示する。
- HTTP のステータスコードは変更しない(存在しないページは 404 のまま返す)。

## 構成

- 「ログインが必要です」のページに準じ、中央寄せでステータスコード・見出し・説明・「ホームへ戻る」ボタンを表示する。
- エラー時にも確実に表示できるよう、サイトヘッダーは表示しない。
- ダークモードの設定に従って表示する。

## 文言

| 場合 | 見出し | 説明 |
|---|---|---|
| 404 | ページが見つかりません | お探しのページは存在しないか、移動または削除された可能性があります。 |
| 上記以外 | エラーが発生しました | 時間をおいて再度お試しください。 |

- 見出しの上に、ステータスコード(例: 404)を小さく表示する。
- 内部の英語メッセージ(例: Survey not found)は表示しない。
- ブラウザのタブ名は「(見出し) | N Portal」とする。

## 操作

- 「ホームへ戻る」を押すと、エラー状態を解除してホームへ移動する。

## 対象外

- 個々の API が返すエラーメッセージの日本語化。
