# 資料共有要件

本文書は資料共有機能のうち、ファイル配信に関する要件を定める(T-008 で新規作成した最小構成。他の要件は今後のタスクで追記する)。

## ファイル配信

- ファイル資料は R2 に保存し、`GET /api/resources/{id}/file` で認証済みユーザーへ配信する。
- 配信ヘッダー(Content-Type・Content-Disposition)は配信時に決定する(R2 オブジェクトのメタデータには依存しない)。
- ファイル種別ごとの Content-Disposition は次のとおりとする。
  - HTML: `inline`(ページとして表示する)
  - Markdown: 専用ビューアーページ(`/resources/{id}`)で表示する
  - その他(PDF・Office・画像等): `inline`(ブラウザの既定動作に委ねる)
- すべての配信に `X-Content-Type-Options: nosniff` を付与する。

### HTML 資料のサンドボックス配信

- HTML 資料の配信には `Content-Security-Policy: sandbox allow-scripts` を付与する。
- これにより投稿 HTML は不透明オリジン(opaque origin)で描画され、スクリプトは動作するが、ポータル本体の Cookie・API にはアクセスできない(投稿 HTML による持続型 XSS の防止)。
- 前提条件として、Cloudflare Access の Cookie の SameSite 属性は `Lax` 以上とする(サンドボックスからの認証付きリクエストを防ぐ)。
- 制約: 不透明オリジンでは `localStorage` 等の Web Storage へのアクセスが例外になる。try/catch なしで参照する投稿 HTML は該当スクリプトが停止する(`allow-same-origin` の追加は隔離を無効化するため行わない)。

## 資料を開くリンク

- ファイル資料の直接リンク(`/api/resources/{id}/file`)は新規タブで開く(`rel="noopener"` を付与)。
- Markdown 資料のビューアーページと議事録へのリンク(資料一覧では議事録のタイトル、資料の詳細ページでは「議事録を見る」)は同一タブで開く。
- URL 資料は外部リンク動作([requirements-links.md](requirements-links.md))に従う。

## 発表応募との紐付け

- 資料は発表募集の応募 1 件と紐付けられる(1 対 1)。紐付けの設定・解除は発表募集側で行う([requirements-speakers.md](requirements-speakers.md) §5)。
- 紐付いた資料も資料一覧に通常どおり掲載する。資料一覧には応募のタイトルを表示しない。
- 紐付け時に `presenter` と `related_minutes_slug` へ応募側の値が反映されるのは、それらが未設定の場合に限る。手動で設定した値は上書きされない。

## 一覧ページの表示

- ページの見出しは「資料一覧」とする。ブラウザのタブ名は「資料共有」、ナビのラベルは「資料」とする。
- 検索欄のラベルは「キーワード検索」、案内文は「タイトル・タグ・投稿者で検索…」とする。検索対象はタイトル・タグ・投稿者(メールアドレス全体)・発表者・ファイル名。
- 絞り込み欄には、種類・タグ・投稿者の行を置く。各行のボタンの左端を揃え、ボタンが 2 行以上に折り返した場合も同じ位置に揃える。
- タグが 1 つも無い場合は、タグの絞り込み欄を表示しない。
- 投稿者の行には「すべて」「自分の投稿」のボタンを置く(初期状態は「すべて」)。「自分の投稿」は、投稿者が利用者自身のメールアドレスと一致する資料のみを表示する(管理者が編集できる他の人の投稿は含めない)。
- 検索語・種類・タグ・投稿者の条件は組み合わせて絞り込める。条件は URL に保持し、「条件をクリア」ですべて解除する。
- 資料が 1 件も無い場合は「資料はまだありません。」を、絞り込みの結果が 0 件の場合は「条件に合う資料はありません。」を表示する。
- 投稿者は、メールアドレスの @ より前のみを表示する(資料の詳細ページも同じ)。
- 一覧は表形式とする。列は左から 資料(タイトル)・種類・タグ・投稿者・日付・議事録・編集と削除 とし、編集と削除の列には見出しを付けない。ファイル名・容量は表示しない。
- 画面幅 1024px 未満では、1 件を 日付・種類・投稿者/資料/タグ/議事録 の 4 段に折り返し、列見出しは表示しない。編集・削除は資料(タイトル)の段の右端に置く。投稿者には「投稿者: 」、議事録には「議事録: 」を付ける。タグ・議事録が無い資料では、その段を表示しない。
- 種類は、文字の左に種類ごとのアイコンを色分けして表示する。対象は投稿時に自動で決まる 12 種(PDF・PowerPoint・Word・Excel・CSV・Text・Markdown・HTML・Image・ZIP・URL・File)とし、それ以外の値は File と同じアイコンで表示する。アイコンは絞り込み欄の種類のボタンにも付ける(選択中のボタンでは文字と同じ色にする)。
- 各行の操作は課題一覧の表に合わせ、ボタンは置かない。
  - 資料を開く: 資料のタイトルをリンクにする(色は課題一覧の議事録のリンクと同じ青)。開き方は「資料を開くリンク」に従う。
  - 議事録: 議事録の列に、関連議事録のタイトルをリンクで表示する。関連議事録が無い資料は空欄とする。関連議事録のタイトルを取得できない場合は「議事録」と表示する。
  - 編集・削除: 課題一覧と同じアイコンのボタン(左から 編集・削除)とし、編集できる資料にのみ表示する。
- 議事録は専用の列、編集・削除は常に同じ並びとし、各操作の横位置を行ごとに変えない。
- 資料の詳細ページから一覧へ戻るボタンは「一覧へ戻る」とする。

## 対象外

- チャット添付ファイル(`GET /api/chat/messages/{id}/file`)は本要件の対象外とし、HTML を含めダウンロード形式で配信する([requirements-chat.md](requirements-chat.md) に従う)。
