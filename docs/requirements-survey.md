# アンケート機能 要件定義書

- 作成日: 2026-10-02
- 更新日: 2026-10-02(T-018 管理者コメントの追加を反映)
- ステータス: 実装完了・運用中

本書は T-018 の起票に伴い新規作成した最小限の As-Built 仕様書。既存実装の全容ではなく、回答の表示と管理者コメントの仕様を記載する。

## 1. 背景・目的

社内 AI 勉強会の感想・要望をアンケートで集め、結果を参加者全員で共有する。自由記述で挙がった要望・課題に運営が応答した内容を、利用者にも分かる形で残す。

## 2. 機能概要

- アンケートの状態は「下書き」「受付中」「終了」の3つ。回答できるのは受付中のみ。
- 設問の種類は、単一選択・複数選択・自由記述の3つ。選択式の設問には「その他」の自由記述を付けられる。
- 回答者は、受付中であれば回答を再送信して内容を変更できる。
- 結果ページ(`/survey/{id}/results`)で、設問ごとの集計と自由記述の回答を表示する(§3)。
- アンケートの作成・編集・削除と、回答へのコメント(§4)は管理画面(`/admin/surveys`)で行う。

## 3. 回答の表示

- 結果ページは回答を匿名で表示する。回答者本人には、自分の回答が分かるように強調して表示する。
- 管理画面の回答閲覧ページ(`/admin/surveys/{id}/responses`)も、回答者を表示しない。

## 4. 管理者コメント

- 管理者は、個々の自由記述回答にコメントを付けられる。対象は、自由記述設問の回答と、選択式設問の「その他」の自由記述。選択式の集計値には付けられない。
- コメントは1つの回答につき1件。後から編集・削除できる。空にして保存すると削除として扱う。
- 本文はプレーンテキストで、1000 文字まで。改行はそのまま表示し、本文に書かれた HTML は文字列として表示する。
- コメントの登録・編集・削除ができるのは、状態が「終了」のアンケートのみ。
- 入力は管理画面の回答閲覧ページで行う。アンケート一覧の「回答」から開く。このページは自由記述の回答を設問ごとに一覧表示する(選択式の集計は表示しない)。
- コメントは結果ページで全利用者に表示する。対象の回答の枠内に、本文と日付(最後に保存した日。JST)を表示する。記入者は表示しない。
- 終了したアンケートを受付中へ戻すことはできる。再開後に回答者が回答を再送信した場合、その回答者の回答に付いていたコメントは削除する。再送信していない回答のコメントは残る。
- アンケートを削除すると、そのコメントも削除する。

### 対象外

- 対応状況(未対応・対応済み)の管理
- 1つの回答への複数コメント
- Markdown による記述
- コメントが付いたことの回答者への通知
- コメントの議事録への自動反映
