# 外部リンクの新規タブ表示

## 目的・背景

サイト内から外部サイトへ遷移する際に、利用者が現在の画面を維持できるよう、外部リンクの新規タブ表示を統一する。現状はリンク種別によって動作が異なるため、今後追加される外部リンクにも適用できる共通処理とする。

## 確定要件

- 全画面の外部 HTTP(S) URL を対象とする。
- 外部 URL は、現在のページと scheme・host・port のいずれかが異なる URL と定義する。別サブドメインおよび別ポートも外部として扱う。
- 外部リンクは新規タブで開き、`rel="noopener noreferrer"` を付与する。
- 同一オリジンの URL および HTTP(S) 以外の URL は、共通処理による新規タブ表示の対象外とする。
- 外部リンクの表示文言・アイコン・スタイルは変更しない。
- 今後追加される外部リンクにも同じ規則を適用できる共通実装とする。

## 受入条件

- 外部 HTTP(S) URL のリンクに `target="_blank"` および `rel="noopener noreferrer"` が設定され、新規タブで開く。
- 同一オリジンと非 HTTP(S) URL には、共通実装が新規タブ表示を自動適用しない。
- 既存のリンク表示に視覚的な変更がない。
- 外部判定の境界条件と、現在存在する外部リンクの共通実装適用を自動テストで確認できる。
