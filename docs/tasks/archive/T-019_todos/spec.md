# Todo 形式の簡易課題管理

## 目的・背景

「AI会議の課題管理が欲しい」という要望への対応として、アンケート回答への管理者コメント(T-018)とは別に、Todo 形式の簡易な課題管理が欲しいとの提案があった。会議で出た宿題や、運営の対応事項を、誰が・いつまでに行うかとあわせて一覧で共有し、完了したかどうかを全利用者が確認できるようにする。

会議中に画面共有しながら、その場で課題を登録・完了にする使い方を想定する。

## 確定要件

### 課題の項目

- **管理対象**: 会議の宿題と運営の対応事項を区別せず、一つの一覧で管理する。種別の項目は持たない。
- **項目**: 件名(必須)、担当(任意)、期限(任意)、議事録(任意)、状態。詳細欄は持たない。
- **件名**: 1行のテキスト。前後の空白を除去して保存する。空では保存できない。件名に書かれた HTML は文字列として表示する。
- **担当**: 自由入力のテキスト。利用者のアカウントとは対応付けない。
- **期限**: 日付。
- **議事録**: 登録済みの議事録から1件を選んで紐付ける。選択肢は開催日の新しい順に並べる。登録時は空欄にしておき、議事録の作成後に編集で設定できる。
- **状態**: 未完了・完了の2段階。完了にした日時を記録する(画面には表示しない)。

### 権限

- 登録・編集・削除・完了の切り替えができるのは管理者のみ。
- 閲覧は全利用者ができる。

### 課題ページ

- 課題の一覧を表示する専用ページを新設する。ページ名は「課題」。
- **レイアウト**: 表形式とする。列は、完了のチェックボックス・課題・担当・期限・議事録。各行の内容は上下中央に揃える。
- **議事録の列**: 紐付けた議事録のタイトルを表示し、その議事録の詳細ページへリンクする。
- **期限超過**: 期限を過ぎた未完了の課題は、期限を赤字で表示する。「超過」等の文字は付けない。期限の当日は超過としない。
- **並び順**: 未完了は登録の新しい順。完了済みは完了にした日時の新しい順。
- **完了済みの扱い**: 通常は未完了のみを表示する。表の最下段の「完了済み(n件)」を押すと、完了済みの課題を展開して表示する。完了済みの件名には取り消し線を付ける。完了済みが0件のときは「完了済み」の行を表示しない。
- **課題が無い場合**: 未完了・完了済みとも0件のときは、課題が登録されていない旨を表示する。
- **狭い画面**: 表は横スクロールで表示する。

### 管理者の操作(課題ページ上)

管理者が課題ページを開いたときだけ、次の操作欄を表示する。管理画面には課題の管理ページを設けない。

- **追加**: 一覧の上に追加欄(件名・担当・期限・議事録・追加ボタン)を常時表示する。
- **完了の切り替え**: 行のチェックボックスで切り替える。完了にした課題は「完了済み」側へ移り、チェックを外すと未完了へ戻る。
- **編集**: 行の右端の鉛筆アイコンを押すと、その行が入力欄に切り替わる。チェックのアイコンまたは Enter キーで保存し、×のアイコンまたは Esc キーで保存せずに閉じる。
- **削除**: 行の右端のゴミ箱アイコンを押し、確認のうえ削除する。削除した課題は元に戻せない。
- 管理者以外には、追加欄・編集と削除のアイコンを表示しない。チェックボックスは操作できない状態で表示する。

### 議事録ページへの表示

- 議事録の詳細ページの本文の下に、その議事録に紐付く課題の一覧を表示する。列は、完了のチェックボックス(操作不可)・課題・担当・期限。見出し・説明文・課題ページへのリンクは置かず、表のみを表示する。本文との間隔は、課題ページの追加欄と表の間隔に揃える。
- 未完了を先に、完了済みを後に並べる。完了済みも折りたたまずに、取り消し線を付けて表示する。
- 管理者を含め、議事録ページでは操作できない(表示のみ)。
- 紐付く課題が無い議事録では、この欄を表示しない。
- 議事録を削除した場合、その議事録に紐付いていた課題は残し、紐付けのみ解除する。

### グローバルナビゲーション

- 「課題」を追加する。位置は「アンケート」の右とする。
- 「資料共有」を「資料」に、「発表募集」を「発表」に短縮する。変更するのはナビのラベルのみで、ページの見出し・タイトル・戻るリンク・管理画面の文言は変更しない。
- 変更後の並びは、ホーム・議事録・スケジュール・アンケート・課題・資料・発表・ニュース・BBS とする。

### その他

- **見た目の確認**: 実装の途中でユーザーが画面を確認し、指摘を反映する。
- **本番 D1**: スキーマの適用は Admin が実施する(エージェントはコマンドの提示まで)。
- **更新履歴**: 一般ユーザーの表示が変わるため `app/utils/changelog.ts` に追記する。

### 対象外

- 3段階の状態(未着手・対応中・完了)、完了時の対応メモ、複数行の詳細欄
- 会議回(スケジュール)との紐付け、議題ページへの表示
- アンケート回答・不具合要望報告からの起票
- トップページへの表示
- 管理者以外による登録・編集・完了(担当者本人による完了を含む)
- 担当と利用者アカウントの対応付け、「自分の課題」の絞り込み
- 絞り込み・検索・並び順の切り替え
- 期限の通知
- 議事録ページでの課題の操作
- ナビ以外の「資料共有」「発表募集」の文言変更
- 管理画面の課題管理ページ

## 受入条件

1. グローバルナビゲーションが、ホーム・議事録・スケジュール・アンケート・課題・資料・発表・ニュース・BBS の順に表示され、「課題」から課題ページへ移動できる。資料・発表の各ページの見出しとタイトルは従来の文言のままである。
2. 管理者が課題ページの追加欄に件名を入力して追加すると、一覧の最上段に表示される。担当・期限・議事録は空のままでも追加でき、ページを再読み込みしても同じ内容が表示される。件名が空(空白のみを含む)の場合は追加できない。
3. 管理者がチェックボックスにチェックを入れると、その課題は未完了の一覧から消え、「完了済み(n件)」の件数が増える。「完了済み」を展開すると取り消し線付きで表示され、チェックを外すと未完了へ戻る。
4. 完了済みは通常は表示されず、「完了済み(n件)」を押すと展開される。完了済みが0件のときは、この行が表示されない。
5. 管理者が鉛筆アイコンを押すと行が入力欄に切り替わり、件名・担当・期限・議事録を変更して保存できる。Esc キーまたは×のアイコンでは保存されずに閉じる。
6. 管理者がゴミ箱アイコンを押すと確認が表示され、承諾すると課題が削除される。取り消すと削除されない。
7. 議事録を紐付けた課題は、議事録の列にその議事録のタイトルが表示され、押すとその議事録の詳細ページへ移動する。
8. 期限を過ぎた未完了の課題は期限が赤字で表示され、「超過」等の文字は付かない。期限が当日以降の課題と、完了済みの課題は赤字にならない。
9. 未完了は登録の新しい順、完了済みは完了にした日時の新しい順に並ぶ。
10. 管理者以外には、追加欄・編集と削除のアイコンが表示されず、チェックボックスは操作できない。管理者以外からの登録・編集・削除・完了の切り替えの要求は拒否される。
11. 議事録の詳細ページの本文の下に、その議事録に紐付く課題(未完了・完了済みの両方)が表のみで表示される。見出しと課題ページへのリンクは表示されない。管理者にも操作欄は表示されない。紐付く課題が無い議事録では、この欄が表示されない。
12. 議事録を削除すると、紐付いていた課題は残り、議事録の列が空になる。
13. 件名に書かれた `<script>` 等の HTML は、文字列として表示される。
14. 課題が1件も無い状態で、課題ページに未登録の旨が表示される。
15. 幅 390px の画面で、表以外の部分に横スクロールが発生しない。ライト・ダーク両テーマで表示が崩れない。
16. `npm test` と `npm run check` が通る。
17. 見た目についてユーザーの確認を得ている(ユーザー実施)。
18. 本番 D1 へのスキーマ適用後、本番環境で課題の登録・完了・表示ができる(実環境・ユーザー実施)。
