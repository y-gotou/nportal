# 議事録詳細の前後ナビゲーション

## 目的・背景

議事録詳細ページには「一覧へ戻る」「チャットを見る」しか導線がなく、前後の回へ移動するには一覧へ戻って探し直す必要がある。議事録の件数増加に伴い振り返りの手間が大きい。前後関係を返す API・データ構造は未実装だが、minutes テーブルの日付順から導出できる。

## 確定要件

- 議事録詳細ページに「前の議事録(過去方向)」「次の議事録(未来方向)」への遷移リンクを追加する。
- 配置はページ上部(既存ボタン列と同エリア)と本文末尾の2箇所(2026-08-27 ユーザー決定)。
- 前後の判定は議事録の日付順(slug = 日付)による。
- 前または次が存在しない場合、該当リンクは表示しない。

## 受入条件

- 中間の議事録では前後両方のリンクが上部・本文末尾に表示され、それぞれ正しい日付の議事録詳細へ遷移する。
- 最古の議事録では「前」が、最新の議事録では「次」が表示されない。

## 検証方法

- 型チェック・ビルド: `npm run check`(エージェント実施)
- 単体テスト: 前後 slug 導出ロジックのテストを追加し `npm test`(エージェント実施)
- ローカルブラウザ確認: `npm run dev` + モックログインで遷移動作を確認(エージェント実施)

## 仕様書反映

### 追加: docs/requirements-minutes.md

詳細ページの前後ナビゲーション仕様(配置2箇所・日付順・端では非表示)を追加する。文書が未作成の場合は T-002 の方針に従い最小限の要件文書を新規作成して記載する。
