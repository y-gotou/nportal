# ニュースページの配色トークン統一

## 目的・背景

`/news` はデザイン案「紙面型」の実装時に、ページ背景と本文色をデザイントークン(`app/assets/css/main.css` の CSS 変数)を経由せず直値で指定した。その結果、ページ背景が他ページと異なり(light `#eceff3` / dark `#0b1120` に対し、他ページは `--background` の `#f8fafc` / `#0f172a`)、サイトヘッダーとの明度差も他ページより大きい。本文色も `text-slate-600 dark:text-slate-300` で、他ページの `text-muted` と不一致である。

罫線と番号による一覧構成(紙面型の本質)は要件どおりに維持したうえで、配色のみをトークン体系に戻し、他ページとの見た目の一貫性を確保する。

## 確定要件

- `/news` のページ背景は `--background` トークン(`bg-background`)に従う。直値指定を廃止する。
- 本文パネルの外枠は、他ページのカード(`app/utils/ui.ts` の `surfaceCardClass`)と同じ `border-border` + `bg-surface` + `shadow-sm` の質感に揃える。独自の影の直値指定を廃止する。
- 記事・ダイジェストの要点まとめ本文は `text-muted` トークンに従う。`text-slate-600 dark:text-slate-300` の直値指定を廃止する。
- 紙面型レイアウト(罫線ベースの番号付き一覧、パネル内の独自見出し、タブバーと掲載日ナビの固定表示、本文の余白、任意値のタイポグラフィ)は変更しない。
- 対象外:
  - 順位番号の淡色(`text-slate-300 dark:text-slate-600`)。対応するトークンが無く、`--border` を流用すると dark で背景と同化する既知の問題(commit `17f6c69`)があるため、現状を維持する。
  - `app/components/PageHero.vue` の `bg-[#2d3748]`。トップページの既存実装であり、本タスクの対象範囲外とする。
  - タブバーの固定位置に用いるヘッダー高さの直値(`top-[73px]`)。配色ではなくレイアウトの指定のため対象外とする。

## 受入条件

- `/news` と `app/components/news/` 配下に、背景色・本文色・影の直値指定(`bg-[#…]`、`text-slate-600` 等、および `shadow-[…]`)が残っていない(順位番号の淡色を除く)。
- light / dark 双方で、`/news` のページ背景が他ページと同一で、本文パネルが他ページのカードと同じ枠線・背景・影で表示される。
- 罫線ベースの一覧、パネル内見出し、タブバーと掲載日ナビの固定表示が従来どおり動作する。
