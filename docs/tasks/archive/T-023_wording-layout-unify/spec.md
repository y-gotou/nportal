# 表記の統一と軽微なレイアウト調整

## 目的・背景

2026-10-02 に、全画面の表記ブレとレイアウト崩れを洗い出し、ヒアリングで項目ごとの対応方針を決めた。対応は 2 つの PR に分け、表示の崩れ・欠落は T-022 で先行して修正した。本タスクは後続分として、表記の統一と軽微なレイアウト調整を扱う。

同じ行き先のボタンが画面ごとに違う文言になっている、同じ意味の語が複数ある、記号の全角・半角が混在している、ボタンの位置がカードごとに変わる、といった不揃いをなくし、利用者が画面ごとに読み替えずに済むようにする。

## 確定要件

### 1. ボタン・リンクの文言

| 対象 | 統一後 | 変更する箇所 |
|---|---|---|
| チャットへの導線 | チャットを開く | 議事録詳細の「チャットを見る」、スケジュールの「チャット」 |
| 議題への導線 | 議題を見る | ホーム・スケジュールの「議題」 |
| 議事録への導線 | 議事録を見る | ホーム・資料一覧・資料詳細の「関連議事録」 |
| 資料への導線 | 資料を開く | 発表募集の「資料を見る」 |
| 詳細ページから一覧へ戻る導線 | 一覧へ戻る | 資料詳細の「資料共有へ戻る」 |
| ホームの見出し横の一覧への導線 | 議事録一覧 / 資料一覧 | 「すべて見る」「資料一覧へ」 |
| ホームの次回会議パネル内の導線 | スケジュール一覧を見る | 「予定一覧を見る」 |
| 課題の編集を中止するアイコンボタン | キャンセル | 「取り消し」 |

- チャットで会議が見つからない場合の「スケジュールへ戻る」は、エラー文中のリンクのため変更しない。
- 主ボタンの「〜する」の有無(「回答を編集」「回答を送信」「資料を投稿」等)は統一しない。

### 2. ページ・機能の名称

- 発表募集ページの見出し「発表者募集」を「発表募集」に変更する。ナビの「発表」は短縮形として残す。
- 一覧ページの見出しを「〇〇一覧」に揃える。「資料共有」を「資料一覧」に、「課題」を「課題一覧」に変更する。ブラウザのタブ名(「資料共有」「課題」)は変更しない。

### 3. 用語

| 対象 | 統一後 | 変更する箇所 |
|---|---|---|
| 会の呼び方(一般名詞) | 会議 | ページ説明文の「今後の勉強会予定」「開催済み勉強会」 |
| topics のラベル | トピック | ホームの「テーマ」 |
| 発表募集への申し込み | 応募 | 「発表を申し込む」→「発表に応募する」、「申し込む」→「応募する」、ページ説明文の「エントリーしてください」→「応募してください」 |
| アンケートの件数表示 | 回答者数: 3人 / 設問数: 3問 | ホーム・アンケート一覧の「回答者 3人」「設問数 3問」 |
| 選択欄の未選択を表す選択肢 | なし | 発表資料の「紐付けなし」、資料フォームの関連議事録の「未選択」、管理画面の発表募集の「紐付けなし」 |

- 活動名としての「社内AI勉強会」「AI勉強会」、入力例の「第1回 社内AI勉強会」、「開催済みの回」「この回で参照した資料」は変更しない。
- 発表募集の「発表テーマ・タイトル」は別の項目のため変更しない。
- 課題の追加欄の「議事録(任意)」は、ラベルのない欄の案内を兼ねるため変更しない。

### 4. 記号

- 省略記号は「…」(三点リーダー)に統一する。「送信中...」「読み込み中...」「保存中...」「更新中...」「作成中...」「削除中...」「複製中...」を対象とする。URL の入力例「https://...」は対象外とする。
- 括弧は半角 `( )` に統一する。「発表時間（分）」「添付画像（任意）」など、画面に表示する文言と読み上げ用の名称の全角括弧を対象とする。
- 疑問符は全角「？」に統一する。チャットの「この投稿を削除しますか?」を対象とする。
- 文末の句点の有無、英数字前後のスペースの有無は統一しない。

### 5. 0 件時・検索 0 件時の文言

- 登録が 0 件のときの文言は「〇〇はまだありません。」に統一する。

  | 画面 | 変更後 |
  |---|---|
  | スケジュール | スケジュールはまだありません。 |
  | 課題 | 課題はまだありません。 |
  | 議題ページ | 議題はまだありません。 |
  | チャット | 投稿はまだありません。 |
  | アンケート結果(自由記述) | 自由記述の回答はまだありません。 |
  | アンケート結果(見出し) | 回答はまだありません |
  | 発表募集(一般・管理) | 応募はまだありません。 |
  | 管理画面の議事録・スケジュール・資料・アンケートの一覧 | 〇〇はまだありません。 |

- ニュースの「まだ公開されていません。」、課題の「未完了の課題はありません。」は意味が異なるため変更しない。
- 検索・絞り込みの結果が 0 件のときの文言は「条件に合う〇〇はありません。」に統一する(議事録・資料)。
- 議事録一覧と資料一覧では、登録そのものが 0 件で条件も指定されていないときは「〇〇はまだありません。」を表示し、検索 0 件と出し分ける。

### 6. 検索欄

- 資料一覧の検索欄のラベル「資料を検索」を、議事録一覧と同じ「キーワード検索」に変更する。
- 資料一覧の検索欄の案内文を「タイトル・タグ・投稿者で検索…」に変更する。検索対象そのものは変更しない。

### 7. 利用者の表示

- 一般画面の発表募集のカードと、資料の「投稿者」は、チャットと同じく「@ より前」のみを表示する。
- 管理画面の「応募者」「送信者」の列と、ヘッダー・利用者メニューの本人表示は、メールアドレス全体のままとする。

### 8. 必須マーク

- 必須を表す「*」の色を 1 色に統一し、ラベルとの間隔を揃える。

### 9. ボタンの配置(カード右側のボタン群)

- PC 幅では、ボタン群の並びを反転し、先頭のボタン(資料一覧では「資料を開く」)が常に右端に来るようにする。後続のボタンは、その左に追加される。
- スマホ幅(本文の下にボタン群が回る幅)では、現状の並び(先頭のボタンが左端)のままとする。
- 対象は、資料一覧、ホーム(受付中のアンケート・最近の資料)、スケジュール(今後の予定・開催済みの回)、アンケート一覧、発表募集のカードとする。ホームの次回会議パネル内のボタン群は左寄せのため対象外とする。

### 10. 軽微なレイアウト

- **発表募集のボタン**: 「編集」「取り下げ」を、同じ行の他のボタンや資料一覧の「編集」「削除」と同じ大きさにする。
- **発表募集のカードの区切り**: スマホ幅で応募者・時間・日時が折り返すとき、区切り記号が行末に残らないようにする。
- **発表募集の見出し**: 見出しと主ボタンの並びを資料一覧と同じ挙動にする(スマホ幅ではボタンが見出しの下に回る)。
- **資料一覧のタグ欄**: タグが 1 つもないときは、「タグ」のラベルだけの行を表示しない。
- **議事録カード**: 議事録一覧のカードの余白を、ホームの「最近の議事録」に揃える。長いタイトルでも日付が折り返さないようにする。
- **検索パネル**: 議事録一覧の検索パネルを、資料一覧と同じ見た目(白背景・標準の入力欄)に揃える。
- **ニュースの大見出し**: スマホ幅で、大見出し「今日のAIニュース」「AIニュース」が語の途中で折り返さず、1 行で表示されるようにする。

### 11. 管理画面

- 発表募集の見出し「発表募集管理」を「発表募集」に変更する(他の見出しと同じく「管理」を付けない)。
- ダッシュボードの「新規追加」を「新規作成」に変更する。
- 編集フォームの処理中の表示「更新中」を「保存中」に変更する(ボタンの「保存する」と対応させる)。
- 入力欄のヒントを「カンマ区切り(例: …)」の形に統一し、発表者の入力例の読点をカンマに変更する。
- 発表募集の列名「ステータス」と、エラー文「ステータスの変更に失敗しました。」の「ステータス」を「状態」に変更する。
- アンケート作成画面の入力例「質問の内容を入力」を「設問の内容を入力」に変更する。

### 対象外

- 更新情報ページの過去の記載の書き換え。
- エラー文の型の統一(「時間をおいて再度お試しください。」の有無)。
- 管理画面の「不具合・要望」の名称。
- 表示の崩れ・欠落(T-022 で対応済み)。

## 受入条件

- 確定要件 1〜8・11 の変更後の文言・記号が、該当するすべての画面で表示される。変更前の表記(ボタンの「関連議事録」、「チャットを見る」「資料を見る」「資料共有へ戻る」「発表者募集」「紐付けなし」「未選択」、進行中表示の「...」、表示文言の全角括弧)が画面に残っていない。資料の投稿フォームの項目名「関連議事録」は、入力項目の名前のため対象外とする。
- 議事録一覧と資料一覧で、登録 0 件・条件未指定のときは「〇〇はまだありません。」、検索 0 件のときは「条件に合う〇〇はありません。」が表示される。
- 一般画面の発表募集のカードと資料の「投稿者」に「@ より前」のみが表示され、管理画面とヘッダーの表示は変わらない。
- PC 幅で、対象のカードの先頭のボタンが、後続のボタンの有無にかかわらず同じ位置(右端)に表示される。スマホ幅では先頭のボタンが左端に表示される。
- 発表募集の「編集」「取り下げ」が他のボタンと同じ高さで表示される。スマホ幅で区切り記号が行末に残らない。スマホ幅で主ボタンが見出しの下に表示される。
- 資料一覧でタグが 0 件のとき「タグ」の行が表示されない。議事録一覧のカードの余白がホームと一致し、長いタイトルでも日付が 1 行で表示される。議事録一覧と資料一覧の検索パネルの背景色・入力欄の大きさが一致する。
- 幅 360・375・414px で、ニュースの大見出しが 1 行で表示され、「最終更新」の時刻も表示される。
- 幅 360〜1400px で、変更した画面のページ全体が横スクロールしない。ダークモードでも表示が崩れない。
- `npm test` と `npm run check` が通る。
