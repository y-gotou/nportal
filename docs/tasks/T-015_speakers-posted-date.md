# 発表者募集カードへの投稿日表示

## 目的・背景

発表者募集ページ(`/speakers`)の応募カードには投稿日が表示されておらず、各応募がいつ投稿されたかを利用者が把握できない。応募日時(`created_at`)を投稿日としてカードに表示する。

`created_at` は UTC で保存され、`datetime('now')` の `YYYY-MM-DD HH:MM:SS` 形式とアプリ登録時の ISO 8601 形式が混在する(T-014 参照)。表示時はいずれの形式も JST の日付に変換する。

確定要件:
- 表示位置はカードのメタ情報行(メールアドレス | 発表時間)の末尾とし、「投稿日 YYYY年M月D日」と表示する。
- 基準は応募日時(`created_at`)とし、応募内容の編集では変わらない。

対象外: 管理画面(発表募集管理・管理トップ)への表示、更新日時(`updated_at`)の表示、時刻の表示、API・DB の変更。

## 受入条件
- `/speakers` の全ステータス(応募中・発表予定・発表済み)のカードのメタ情報行に「投稿日 YYYY年M月D日」が表示される。
- `created_at` の 2 形式(`YYYY-MM-DD HH:MM:SS` / ISO 8601)のいずれでも JST の日付で表示される(UTC 15:00 以降の応募は翌日付となる)。
- 管理画面の表示は変わらない。
