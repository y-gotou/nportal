# T-024 実装計画

## 設計判断

1. **表のマークアップ**: `<table>` を使い、画面幅 1024px 未満では行を grid に切り替える(`lg:` で table の表示に戻す)。折り返しの段は、行に領域(grid-template-areas)を定義し、各セルを割り当てて作る。編集・削除のアイコンをタイトルと同じ段の右端に置くため、当初の flex の折り返し(`order` と `basis-full`)から変更する。表として並ぶ幅では列幅の計算をブラウザに任せられ、課題ページの表と同じ構造になるため。表は別コンポーネントに分けず、`app/pages/resources/index.vue` に書く(編集・削除の処理と状態を共有しており、既存のテストもこのファイルを対象にしているため)。
2. **操作の位置の固定**: 議事録は専用の列、編集・削除は専用の列に常に同じ並びで置く。表示しない操作の位置を確保する空枠は不要になるため、当初の実装から削除する。議事録のタイトルは、ページが既に取得している議事録の一覧(投稿フォームの選択肢用)から引く。API は変更しない。編集・削除のアイコンのボタンは、課題一覧の表と同じ指定にする(使用箇所が 2 つになるため、指定を `app/utils/ui.ts` に移して共有する)。
3. **種類のアイコン**: 種類からアイコン(lucide)と配色クラスを引く対応を `app/utils/resources.ts` に置く。配色は、ライト用とダーク用を同じ行に書く(`tests/dark-mode-colors.test.mjs` の検査対象)。

   | 種類 | アイコン | 色 |
   |---|---|---|
   | PDF | FileText | red |
   | PowerPoint | Presentation | orange |
   | Word | FileType | blue |
   | Excel | FileSpreadsheet | green |
   | CSV | Table | teal |
   | Text | TextAlignStart | muted |
   | Markdown | Hash | violet |
   | HTML | Code | amber |
   | Image | Image | pink |
   | ZIP | FileArchive | yellow |
   | URL | Link | sky |
   | File・12 種以外 | File | muted |

4. **自分の投稿の判定**: `useCurrentUser()` のメールアドレスと、資料の `submittedBy` の一致で判定する(発表募集ページと同じ方法)。資料の `canEdit` は管理者にも真となるため使わない。API とデータは変更しない。URL のクエリは `mine=1` とする。
5. **絞り込み判定の関数化**: 条件が 1 つ増えるため、ページ内の `matchesSelectedFilters` を `app/utils/resources.ts` の純粋関数へ移し、単体テストを付ける。
6. **絞り込み欄の整列**: 種類・タグ・投稿者の 3 行を、見出しの列とボタン群の列からなる 1 つの grid にまとめる。ボタン群は 2 列目の中で折り返すため、折り返した行も左端が揃う。タグが 1 つも無いときにタグの行を表示しない挙動は維持する。
7. **タイトルのリンク**: 色は課題一覧の議事録のリンクと同じ指定(`text-blue-600 hover:underline dark:text-blue-400`)にする。当初の行用の小型ボタンの指定は削除する。

## 影響範囲

- 画面: 資料一覧(`app/pages/resources/index.vue`)。
- 表示用ユーティリティ: `app/utils/resources.ts`(種類のアイコンの対応、絞り込み判定)。
- テスト: 新規 `tests/resources-utils.test.ts`。`tests/card-layout.test.mjs` の資料一覧に関する期待値(ボタン群の反転、タグ行の表示条件、削除ボタンの指定)を新しい構造に合わせて更新する。
- 課題一覧の表(`app/components/todo/TodoTable.vue`): アイコンのボタンの指定を共有の定数に置き換える(見た目は変えない)。
- 恒久仕様書: `docs/requirements-resources.md`(「発表応募との紐付け」「一覧ページの表示」「資料を開くリンク」)。
- 更新情報: `app/utils/changelog.ts` に `improvement` を 1 項目追記する。
- API・データベース・設定の変更は無い。
