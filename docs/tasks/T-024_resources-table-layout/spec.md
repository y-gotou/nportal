# 資料一覧の表形式化と絞り込みの拡充

## 目的・背景

資料一覧のカードは、日付・種類/タイトル/タグ/ファイル名・容量/投稿者/発表名を縦に積んでおり、1 件あたり最大 6 段になる。件数が増えると一覧として見通しにくい。

表示する項目を絞って 1 件 1 行の表形式にし、一覧性を上げる。併せて、種類をアイコンで見分けられるようにし、自分の投稿だけを表示する絞り込みを追加する。

## 確定要件

### 1. 一覧の形式

- 一覧を表形式にする。列は左から 資料(タイトル)・種類・タグ・投稿者・日付・ボタン とする。列見出しは「資料」「種類」「タグ」「投稿者」「日付」とし、ボタンの列には見出しを付けない。
- ファイル名・容量と、紐付いた発表応募のタイトル(「発表: 〜」)は表示しない。
- 並び順、投稿者の表示(@ より前のみ)、日付の形式、0 件時の文言は変更しない。

### 2. 狭い幅での表示

- 画面幅 1024px 未満では、1 件を次の 4 段に折り返す。列見出しは表示しない。
  1. 日付・種類・投稿者(投稿者には「投稿者: 」を付ける)
  2. 資料(タイトル)
  3. タグ(タグが無い資料では段ごと表示しない)
  4. ボタン

### 3. ボタン

- ボタンは小型にし、表記を「開く」「議事録」「編集」「削除」とする。リンク先・動作・表示条件は現行の「資料を開く」「議事録を見る」「編集」「削除」と同じとする。
- 表として並ぶ幅では、左から 削除・編集・議事録・開く の順とし、「開く」を右端に置く。折り返した幅では、左から 開く・議事録・編集・削除 の順とする。
- 表示しないボタン(議事録が無い資料の「議事録」、編集できない資料の「編集」「削除」)の位置も空けておき、各ボタンの横位置を行ごとに変えない。折り返した幅でも同じとする。

### 4. 種類のアイコン

- 種類の文字の左に、種類ごとのアイコンを色分けして表示する。対象は投稿時に自動で決まる 12 種(PDF・PowerPoint・Word・Excel・CSV・Text・Markdown・HTML・Image・ZIP・URL・File)とする。
- 12 種以外の値が登録されている資料は、File と同じアイコンで表示する。
- アイコンは、一覧の種類の列と、絞り込み欄の種類ボタンに付ける。選択中の種類ボタンでは、アイコンを文字と同じ色にする。
- 「種類」という表記は変更しない。

### 5. 自分の投稿の絞り込み

- 絞り込み欄に「投稿者」の行を追加し、「すべて」「自分の投稿」のボタンを置く。初期状態は「すべて」とする。
- 「自分の投稿」は、投稿者が利用者自身のメールアドレスと一致する資料とする。管理者が編集できる他の人の投稿は含めない。
- 検索語・種類・タグの条件と組み合わせて絞り込める。「条件をクリア」で「すべて」に戻る。
- 検索語・種類・タグと同じく、条件を URL に保持する。

### 6. 絞り込み欄の整列

- 種類・タグ・投稿者の各行で、ボタンの左端を揃える。ボタンが 2 行以上に折り返した場合も、折り返した行の左端を同じ位置に揃える。

### 対象外

- Markdown 資料の詳細ページ(ファイル名・投稿者の表示を含む)。
- 管理画面の資料一覧。
- キーワード検索の対象(ファイル名・発表者を含め変更しない)。
- ホームの「最近の資料」。

## 受入条件

- 一覧が確定要件 1 の列構成の表で表示され、ファイル名・容量・発表名が表示されない。
- 議事録が無い資料、編集できない資料でも、各ボタンの横位置が他の行と一致する。
- 画面幅 1024px 未満で 4 段に折り返し、ページ全体が横スクロールしない。
- 種類の列と種類ボタンにアイコンが表示され、ダーク表示でも判別できる。
- 「自分の投稿」を選ぶと自分の投稿のみが表示され、再読み込み後も条件が残る。
- 種類・タグ・投稿者のボタンの左端が、タグの折り返し時も含めて揃う。
- `npm test` と `npm run check` が通る。

## 仕様書反映

### 変更: `docs/requirements-resources.md`「発表応募との紐付け」

- 「紐付けがある場合のみ、カードに『発表: {応募タイトル}』をテキストで表示する」を削除し、資料一覧には応募のタイトルを表示しない旨に書き換える。

### 変更: `docs/requirements-resources.md`「一覧ページの表示」

- 各カードのボタン群の記載(「資料を開く」「議事録を見る」「編集」「削除」の並びと反転)を、確定要件 3 の内容に書き換える。
- 追加: 表の列構成と表示しない項目、狭い幅での折り返し、種類のアイコン、「投稿者」の絞り込み、絞り込み欄の整列。

### 変更: `docs/requirements-resources.md`「資料を開くリンク」

- 議事録へのリンクの記載に、資料一覧でのボタン名(「議事録」)を追記する。
