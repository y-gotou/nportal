# T-022 実装計画

## 設計判断

### ニュースのタブバー(`app/pages/news.vue`)

- タブのボタンに `whitespace-nowrap` を付け、文字の折り返しを止める。
- タブバーに `flex-wrap` を付け、収まらない幅では掲載日ナビを次の段へ回す。掲載日ナビには `ml-auto` を付け、1 行のときも 2 段のときも右寄せにする。
- 画面幅で切り替える指定(`sm:` 等)は使わない。タブと掲載日ナビの幅の合計で自然に折り返すため、文言や日付の幅が変わっても追従する。計算上、折り返すのは画面幅がおよそ 510px 未満のとき。
- 固定表示(`sticky top-[73px]`)は変更しない。2 段のときはバーの高さが増える。
- タブ名は `useSeoMeta` で「AIニュース」と説明文を設定する(既定のレイアウトが「| N Portal」を付ける)。

### 管理画面の発表募集の表(`app/pages/admin/speakers.vue`、`app/components/admin/AdminDeleteButton.vue`)

- 表の枠を `overflow-hidden` から `overflow-x-auto` に変え、収まらない幅では枠内で横スクロールさせる。
- 列見出しと「時間」列の値に `whitespace-nowrap` を付ける。
- 「削除」ボタンは、共通部品 `AdminDeleteButton` のボタン自体に `whitespace-nowrap` を付ける。セル側に付けると、ボタンの下に出るエラー文まで折り返さなくなるため。他の管理画面の「削除」ボタンにも同じ指定が効くが、表示は変わらない(折り返さなくなるのみ)。
- 他の管理画面の表(議事録・スケジュール・資料・アンケート・不具合要望)は、折り返しが確認されていないため変更しない。

### ダークモードの配色

- **ホームの「受付中」バッジ**(`app/pages/index.vue`): 直書きの配色を、アンケート一覧と同じ `surveyStatusClass`(`app/utils/status.ts`)の呼び出しに置き換える。
- **管理画面のエラー表示**(5 か所): `bg-red-50 text-red-600` に `dark:bg-red-900/20 dark:text-red-400` を追加する。チャットのエラー表示と同じ組み合わせ。対象は `AdminScheduleForm.vue`、`AdminMinutesForm.vue`、`admin/surveys/index.vue`、`admin/surveys/new.vue`、`admin/surveys/[id]/edit.vue`。
- **回答済みアンケートの注意書き**(`admin/surveys/[id]/edit.vue`): `dark:border-amber-800 dark:bg-amber-900/20 dark:text-amber-400` を追加する。発表応募の「応募中」バッジと同じ組み合わせ。
- **赤字のエラー文**(3 か所): `text-red-600` に `dark:text-red-400` を追加する。対象は `AdminFormField.vue`、`AdminDeleteButton.vue`、`AdminSurveyQuestionEditor.vue`。
- 同じ指定が複数箇所に並ぶが、共通の定数へのまとめ直しは行わない(修正の範囲を配色の追加に留める)。

計画の作成中に、同じ原因の配色漏れを 2 か所見つけた。G2 で要件への追加を確認する。

- **資料の投稿フォームの切り替えボタン**(`ResourceSubmissionForm.vue`、一般画面): 選択中の「URL」「ファイル」の文字色 `text-blue-600` にダーク用の指定がなく、暗い背景で読みにくい。`dark:text-blue-400` を追加する。
- **管理画面の「+ 設問を追加」ボタン**(`AdminSurveyQuestionEditor.vue`): マウスを重ねたときの `hover:bg-blue-50 hover:text-blue-600` にダーク用の指定がない。`dark:hover:bg-blue-900/20 dark:hover:text-blue-400` を追加する。

### エラーページ(`app/error.vue`、`app/utils/error-page.ts`)

- Nuxt の規約どおり `app/error.vue` を新設する。エラー時は `app/app.vue` とレイアウトを経由せず、このファイルだけが表示される。
- 見出しと説明の出し分け(404 とそれ以外)は、`app/utils/error-page.ts` の関数に切り出し、単体テストの対象にする。
- レイアウトを経由しないため、ページ背景と文字色(`min-h-screen bg-background text-foreground`)、タブ名の「| N Portal」は `error.vue` 側で指定する。
- 見た目は `app/pages/login.vue` に合わせる(`PageContainer` の narrow、中央寄せ)。鍵のアイコンの位置にステータスコードを置く。ボタンは `primaryButtonClass` を使う。
- 「ホームへ戻る」は `clearError({ redirect: "/" })` を呼ぶ。リンクでの移動ではエラー状態が残るため。
- ダークモードは、`nuxt.config.ts` の head に登録済みのスクリプトが `<html>` に `dark` を付けるため、追加の処理は不要。
