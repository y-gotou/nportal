# 表示の崩れ・欠落の修正

## 目的・背景

2026-10-02 に、全画面の表記ブレとレイアウト崩れを洗い出した(ローカル環境、PC 幅 1280px とスマホ幅 375px)。対応は 2 つの PR に分ける方針とし、本タスクは先行分として、表示の崩れ・欠落にあたる次の 6 項目を扱う。表記の統一と軽微なレイアウト調整は、後続のタスクで扱う。

1. **ニュースのタブ(スマホ幅)**: 掲載日ナビが表示されると、タブ「今日」「週次ダイジェスト」が 1 文字ずつ縦に折り返す。375px 幅でタブバーの高さが約 204px になる。
2. **管理画面の発表募集の表**: 1280px 幅で、「削除」ボタン、列見出し「時間」、値「20分」が縦に折り返す。
3. **ホームの「受付中」バッジ(ダークモード)**: ダークモード用の配色がなく、白いバッジのまま表示される。
4. **管理画面のエラー表示・注意書き(ダークモード)**: ダークモード用の配色がなく、明るい配色のまま表示される。
5. **ニュースのタブ名**: ブラウザのタブ名にページ名がなく、「N Portal」だけになる。
6. **エラーページ**: 存在しないページなどを開くと、Nuxt 既定の英語のエラーページが表示される。

## 確定要件

### ニュースのタブバー

- タブ「今日」「週次ダイジェスト」の文字は、どの画面幅でも折り返さない。
- タブと掲載日ナビが 1 行に収まらない幅では、掲載日ナビをタブの下の段に表示する。1 行に収まる幅では、従来どおり 1 行(左にタブ、右に掲載日ナビ)とする。
- 2 段になる場合も、サイトヘッダーの直下への固定表示を維持する。

### 管理画面の発表募集の表

- 「削除」ボタン、列見出し、「時間」列の値は折り返さない。
- 表が画面幅に収まらない場合は、表の枠内で横スクロールする。ページ全体は横スクロールさせない。

### ダークモードの配色

- ホームの「受付中」バッジは、アンケート一覧の「受付中」バッジと同じ配色にする(ライト・ダークとも)。
- 管理画面の次の表示に、ダークモード用の配色を付ける。配色は一般画面の同種の表示に合わせる。
  - スケジュール・議事録・アンケートの作成/編集フォームのエラー表示
  - アンケート一覧の複製エラーの表示
  - 回答済みアンケートの編集画面の注意書き
  - 入力項目・削除ボタン・設問欄の赤字のエラー文
  - 設問欄の「+ 設問を追加」ボタンと、設問・選択肢の削除アイコン(マウスを重ねたときの配色)
- 資料の投稿フォームの切り替えボタン(「URL」「ファイル」)は、選択中の文字色にダークモード用の配色を付ける。

### ニュースのタブ名

- タブ名を「AIニュース | N Portal」とする。日次・週次のどちらのタブでも、過去の掲載日を表示していても同じとする。
- 他のページと同様に、ページの説明文も設定する。

### エラーページ

- 日本語のエラーページを新設する。存在しない URL を開いた場合や、ページの表示に必要なデータを取得できなかった場合に表示する。
- 構成は「ログインが必要です」のページに準じる(中央寄せの見出し・説明・「ホームへ戻る」ボタン)。エラー時にも確実に表示できるよう、サイトヘッダーは表示しない。
- 表示内容は次のとおりとする。

  | 場合 | 見出し | 説明 |
  |---|---|---|
  | 404 | ページが見つかりません | お探しのページは存在しないか、移動または削除された可能性があります。 |
  | 上記以外 | エラーが発生しました | 時間をおいて再度お試しください。 |

- 見出しの上に、ステータスコード(例: 404)を小さく表示する。内部の英語メッセージ(例: Survey not found)は表示しない。
- 「ホームへ戻る」を押すと、エラー状態を解除してホームへ移動する。
- タブ名は「(見出し) | N Portal」とする。
- ダークモードの設定に従って表示する。

### 対象外

- 表記の統一と軽微なレイアウト調整(後続のタスクで扱う)。
- 個々の API が返す英語のエラーメッセージの日本語化。
- 受付終了のアンケートの回答 URL が 404 になる挙動の変更。

## 受入条件

- ニュースページで掲載日ナビが表示されている状態で、幅 360px・375px・414px のいずれでもタブの文字が折り返さず、タブと掲載日ナビを操作でき、ページ全体が横スクロールしない。幅 768px 以上では、従来どおり 1 行で表示される。
- 管理画面の発表募集の表で、幅 1280px・1024px のいずれでも「削除」ボタン・列見出し・「時間」列の値が折り返さず、ページ全体が横スクロールしない。
- ダークモードで、ホームの「受付中」バッジがアンケート一覧の「受付中」バッジと同じ配色で表示される。管理画面のエラー表示・注意書き・赤字のエラー文・設問欄のボタン(「+ 設問を追加」と削除アイコン)と、資料の投稿フォームの切り替えボタンが、暗い背景に合う配色で表示される。ライトモードの表示は変わらない。
- ニュースページのタブ名が「AIニュース | N Portal」になる。
- 存在しない URL、存在しない議事録の URL、受付終了のアンケートの回答 URL のいずれでも、日本語のエラーページ(404)が表示され、「ホームへ戻る」でホームへ移動できる。英語の既定エラーページは表示されない。
- `npm test` と `npm run check` が通る。
