# アンケート回答への管理者コメント

## 目的・背景

「AI会議の課題管理が欲しい」という要望があった。ここでの「課題」は、アンケートの自由記述で挙がった要望・課題を指す。運営がそれぞれに対応したかどうかを、利用者にも分かる形で残したい。

アンケートは会議中に回答する運用で、内容は議事録へ手作業で転記している。現状の結果ページは回答を匿名で一覧表示するのみで、運営からの応答を記録する手段がない。

## 確定要件

- **コメントの単位**: 個々の自由記述回答ごとに付ける。自由記述設問の回答と、選択式設問の「その他」の自由記述を対象とする。選択式の集計値には付けない。
- **件数**: 1つの回答につき1件とする。管理者は後から編集・削除できる。空にして保存すると削除として扱う。
- **形式**: プレーンテキストとする。改行はそのまま表示する。本文に書かれた HTML は文字列として表示する。
- **コメントできる時期**: 状態が「終了」のアンケートに限り、登録・編集・削除できる。「下書き」「受付中」のアンケートでは操作できない。
- **入力**: 管理画面から入力する。管理画面に回答閲覧ページを新設し、アンケート一覧から開けるようにする。このページは自由記述回答を設問ごとに一覧表示し、回答ごとにコメントを入力できる。選択式の集計は表示しない(結果ページで確認する)。
- **匿名性**: 回答閲覧ページでも回答者は表示しない。
- **公開範囲**: コメントは結果ページで全利用者に表示する。対象の回答の直下に、回答と区別できる見た目で表示する。
- **表示する情報**: コメント本文と日付(最後に保存した日)のみ。記入者と「運営コメント」等のラベルは表示しない(運営からのコメントである旨は運用で周知する)。
- **状態**: 未対応・対応済みといった状態は持たない。コメントの有無で代替する。
- **受付の再開**: 終了したアンケートを「受付中」へ戻す操作は従来どおり可能とする。再開後に回答者が回答を再送信した場合、その回答者の回答に付いていたコメントは削除する。再送信していない回答のコメントは残し、表示も続ける。
- **アンケートの削除**: アンケートを削除すると、そのコメントも削除する。
- **見た目の確認**: 実装の途中でユーザーが画面を確認し、指摘を反映する。
- **本番 D1**: スキーマの適用は Admin が実施する(エージェントはコマンドの提示まで)。
- **更新履歴**: 一般ユーザーの表示が変わるため `app/utils/changelog.ts` に追記する。

### 対象外

- コメントの議事録への自動反映(転記は手作業のまま)
- 対応状況(未対応・対応済み)の管理
- 1つの回答への複数コメント(追記式)
- Markdown による記述
- コメントが付いたことの回答者への通知
- 管理画面での回答者の表示

## 受入条件

1. 管理画面のアンケート一覧から回答閲覧ページを開ける。自由記述回答(「その他」の自由記述を含む)が設問ごとに一覧表示され、回答者は表示されない。
2. 終了したアンケートの回答にコメントを保存すると、再度開いたときに同じ内容(改行を含む)が表示される。編集と削除ができ、空にして保存すると削除される。
3. 下書き・受付中のアンケートでは、コメントの登録・編集・削除ができない。
4. 管理者以外は、コメントの登録・編集・削除ができない。
5. 結果ページで、コメントのある回答の直下にコメント本文と日付が表示される。管理者以外の利用者にも表示され、記入者は表示されない。
6. コメント本文の改行が保持され、`<script>` 等の HTML は文字列として表示される。
7. コメントの無い回答と選択式の集計表示は、現状から変化しない。
8. 受付を再開して回答者が回答を再送信すると、その回答者の回答に付いていたコメントは削除され、他の回答のコメントは残る。
9. アンケートを削除すると、そのコメントも削除される。
10. `npm test` と `npm run check` が通る。
11. 見た目についてユーザーの確認を得ている(ユーザー実施)。
12. 本番 D1 へのスキーマ適用後、本番環境でコメントの登録と表示ができる(実環境・ユーザー実施)。
