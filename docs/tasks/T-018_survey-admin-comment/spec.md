# アンケート回答への管理者コメント

## 目的・背景

「AI会議の課題管理が欲しい」という要望があった。ここでの「課題」は、アンケートの自由記述で挙がった要望・課題を指す。運営がそれぞれに対応したかどうかを、利用者にも分かる形で残したい。

アンケートは会議中に回答する運用で、内容は議事録へ手作業で転記している。現状の結果ページは回答を匿名で一覧表示するのみで、運営からの応答を記録する手段がない。

## 確定要件
<!-- G1 未承認。以下は 2026-10-01 に会話上で合意した要件案。ヒアリング中の未確定点は log.md の引き継ぎサマリを参照 -->

- **コメントの単位**: 個々の自由記述回答ごとに付ける。自由記述設問の回答と、選択式設問の「その他」の自由記述を対象とする。選択式の集計値には付けない。
- **公開範囲**: コメントは結果ページで全利用者に表示する。
- **状態**: 未対応・対応済みといった状態は持たない。コメントの有無で代替する。
- **入力**: 管理画面から入力する。管理画面に回答を閲覧するページを新設する。
- **本番 D1**: スキーマ変更が必要な場合、本番への適用は Admin が実施する(エージェントはコマンドの提示まで)。
- **更新履歴**: 一般ユーザーの表示が変わるため `app/utils/changelog.ts` に追記する。

### 対象外

- コメントの議事録への自動反映(転記は手作業のまま)
- 対応状況(未対応・対応済み)の管理

## 受入条件
<!-- ヒアリング完了後に確定する。以下は合意済みの要件案から導ける範囲の案 -->

1. 管理者は、管理画面で自由記述回答(「その他」の自由記述を含む)にコメントを付けられる。
2. コメントのある回答は、結果ページでコメントとともに表示される。管理者以外の利用者にも表示される。
3. コメントの無い回答と選択式の集計表示は、現状から変化しない。
4. 管理者以外はコメントを登録・変更できない。
5. `npm test` と `npm run check` が通る。
6. 本番環境でコメントの登録と表示ができる(実環境・ユーザー実施)。

## 仕様書反映

アンケート機能の恒久仕様書が存在しないため、`docs/requirements-survey.md` を最小限の内容で新規作成する。記載内容はヒアリング完了後に確定する。
