# 発表応募と資料の紐付け

## 目的・背景

発表者募集(`/speakers`)の応募と、資料共有(`/resources`)に投稿された発表資料が現状は独立している。両者は `minutes_slug` を介して間接的に繋がるのみで、発表回の議事録が作成されるまでは資料に辿り着けない。

応募 1 件に発表資料 1 件を直接紐付けられるようにし、発表者募集ページから資料へ、資料一覧から発表へ、それぞれ辿れる状態にする。

## 確定要件

### 紐付けモデル

- 応募 1 件に対して資料 1 件を紐付ける。また資料 1 件も応募 1 件までとする(**1 対 1**)。
- 紐付ける資料は、資料共有に**投稿済みの既存資料から選択**する。
- すでに他の応募に紐付けられている資料は選択候補に含めない。API に直接指定された場合はエラーとする。
- 紐付けなし(解除)を選択できる。

### 操作権限・候補範囲

- 応募者本人が、発表者募集ページの自分の応募カード上の資料セレクトから設定・変更・解除できる。候補は `submitted_by` が本人である資料のみ。
- 管理者が、発表募集管理ページ(`/admin/speakers`)から設定・変更・解除できる。候補は全資料。
- 一般ユーザー用 API は、本人以外が投稿した資料の指定を拒否する。
- 応募ステータス(応募中・発表予定・発表済み)による制約は設けない。発表済みの応募は既存仕様により本人の編集(タイトル・発表時間・備考・取り下げ)ができないが、資料の紐付けはこの制限の対象外とし、発表後の資料掲載を可能にする。そのため紐付けは応募の編集モーダルではなくカード上のセレクトで行う。

### 表示

- 発表者募集ページの応募カードに、紐付けがある場合のみ「資料を見る」リンクを表示する。文言は固定とし、既存の「議事録を見る」リンクと並べる。未紐付けの場合は表示しない。
- 遷移先は資料の種別に応じた既存の資料参照動線に従う([requirements-resources.md](../../requirements-resources.md)「資料を開くリンク」)。
- 資料共有ページには紐付け済みの資料も従来どおり掲載する。紐付けがある場合のみ、紐付く応募のタイトルをテキストで表示する(リンクにはしない)。

### 資料側項目の自動反映

- 紐付けが設定・更新された時点で、資料の `presenter` が未設定であれば応募者のメールアドレスを反映する。
- 同様に、資料の `related_minutes_slug` が未設定で、応募に `minutes_slug` が設定されていればそれを反映する。
- 反映は紐付け時の 1 回限りではなく、**応募側の変更に追従**する。管理者が後から応募の `minutes_slug` を設定・変更した場合も、紐付く資料の `related_minutes_slug` が未設定であれば反映する。
- いずれも**未設定の項目のみ**を対象とし、手動で入力済みの値は上書きしない。

### 資料削除時

- 紐付いている資料の削除は従来どおり許可する。削除時に応募側の紐付けを自動解除し、発表者募集ページの「資料を見る」リンクは表示されなくなる。

### 更新履歴

- 一般ユーザーの体験が変わる変更のため、`app/utils/changelog.ts` に 1 項目追記する。

## 対象外

- 応募フォームからの資料の新規アップロード(資料の投稿は従来どおり資料共有ページで行う)。
- 1 応募への複数資料の紐付け、および 1 資料の複数応募からの参照。
- 資料側から発表者募集ページへのリンク遷移(テキスト表示のみとする)。
- 資料の `presenter` を表示名へ変換する仕組み(発表者募集ページの既存表示と同じくメールアドレスをそのまま用いる)。
- 手動設定済みの `presenter` / `related_minutes_slug` の上書き。

## 受入条件

- 自分の応募カードに資料セレクトが表示され、候補が「紐付けなし」＋本人が投稿した未紐付け資料＋現在紐付いている資料に限定される。発表済みの応募でも操作できる。
- 他人の応募カードには資料セレクトが表示されない。
- 発表募集管理ページで、管理者が全資料から紐付けの設定・変更・解除を行える。
- 紐付けのある応募カードに「資料を見る」リンクが表示され、当該資料へ遷移する。未紐付けの応募カードには表示されない。
- 資料一覧カードに、紐付く応募のタイトルがテキストで表示される(リンクにならない)。紐付けのない資料には表示されない。
- 紐付け時、資料の `presenter` が未設定なら応募者のメールアドレスが、`related_minutes_slug` が未設定で応募に `minutes_slug` があればその値が反映される。設定済みの値は変化しない。
- 管理者が応募の `minutes_slug` を後から設定・変更した際も、紐付く資料の `related_minutes_slug` が未設定であれば反映される。
- 他の応募に紐付け済みの資料を API に直接指定した場合、エラーとなり紐付けが成立しない。
- 一般ユーザー用 API に他人が投稿した資料を指定した場合、エラーとなり紐付けが成立しない。
- 紐付いている資料を削除すると、応募の紐付けが解除され「資料を見る」リンクが消える。
- `npm test` と `npm run check` が成功する。
