# 発表募集管理ステータス欄のSSR表示不具合

## 目的・背景

管理画面の発表募集管理ページ(/admin/speakers)のステータスドロップダウンは `<select :value>` で選択状態を指定しているが、select の value 属性は HTML として無効なため SSR で選択状態が出力されず、ページ読み込み直後は実ステータスに関係なく先頭選択肢「応募中」が表示される(T-004 の検証中に発見)。T-004 で新設した議事録ドロップダウンと同じく、option の `:selected` 指定に修正する(既存パターンの踏襲)。

## 受入条件

- /admin/speakers をリロードした直後、各行のステータスドロップダウンが D1 上の実際のステータス(応募中・発表予定・発表済み)を選択状態で表示する。
- ステータス変更の保存動作が従来どおり機能する。

## 仕様書反映

なし(表示不具合の修正のみ。docs/requirements-speakers.md に該当記載なし)。

## 検証方法

テンプレートのみの修正でコンポーネントテスト基盤が無いため、自動テストは追加せずブラウザ確認で検証する。

### エージェント実施
- [ ] `npm run check`(型チェック・ビルド)
