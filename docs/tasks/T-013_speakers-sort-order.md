# 発表者募集の並び順を投稿日の古い順に変更

## 目的・背景

発表者募集ページの応募一覧は、応募日時(`created_at`)の新しい順に並んでいる。応募中・発表予定は申し込みを受け付けた順に消化する運用のため、投稿が古いものを上に表示したい。発表済みは直近の発表を参照する機会が多いため、新しい順を維持する。

一覧を返す `/api/speakers` は発表者募集ページと管理画面(発表募集管理・管理トップ)で共有しており、共通クエリ側で並び順を変更する。管理画面の表示順も同様に変わる。

## 受入条件
- 応募中(`pending`)・発表予定(`scheduled`)の応募が `created_at` の昇順(古い順)で並ぶ。
- 発表済み(`done`)の応募が `created_at` の降順(新しい順)のままである。
- ステータスのグループ順(応募中 → 発表予定 → 発表済み)が変わらない。
