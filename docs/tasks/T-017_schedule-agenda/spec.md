# 会議スケジュールへの議題追加

## 目的・背景

会議の予定内容を事前に簡単に共有したいという要望があった。現状のスケジュールはタイトルとトピック(タグ)のみで、予定内容を文章で記載する欄がない。

会議中は、ブラウザのウィンドウを2つ並べて(片方にアンケート、もう片方に議題)画面共有する使い方を想定する。このため、議題は単独のページとして開けるようにする。

## 確定要件

- **入力**: 管理画面のスケジュール作成・編集フォームに「議題」欄を追加する。任意入力の複数行テキストとする。
- **保存**: 前後の空白を除去して保存する。空の場合は未設定として扱う。
- **議題ページ**: 議事録と同様に、回ごとの単独ページとして表示する。URL は回ごとに固定とする。会議のタイトル・開催日時・開催場所・トピックと、議題の本文を表示し、スケジュール一覧へ戻る導線を置く。
- **導線**: `/schedule` の各回カード(今後の予定・開催済みの回の両方)とトップページの次回予定に「議題」ボタンを置く。位置は既存のボタン列の、チャットのボタンの左とする。押すと議題ページへ移動する。
- **本文の表示**: 改行を保持したプレーンテキストとして表示する。HTML・Markdown は解釈しない。
- **未入力の回**: 「議題」ボタンを表示しない。議題ページを直接開いた場合は、議題が未登録である旨を表示する。存在しない回の議題ページは 404 とする。
- **既存項目**: トピック(タグ)は変更せず併存させる。
- **見た目の確認**: 実装の途中でユーザーが画面を確認し、指摘を反映する。
- **本番 D1**: `schedule` テーブルへの列追加は Admin が実施する(エージェントはコマンドの提示まで)。
- **更新履歴**: 一般ユーザーの表示が変わるため `app/utils/changelog.ts` に追記する。

### 対象外

- 議題のモーダル表示・カード内での展開表示・ボタン近くへの重ね表示
- 議題の Markdown 対応
- チャット画面・管理画面のスケジュール一覧での議題表示
- 議題の議事録への連携

## 受入条件

1. 管理画面で議題を入力して保存すると、再編集時に同じ内容(改行を含む)が表示される。
2. 議題のある回は `/schedule` のカード(今後の予定・開催済みの回)に「議題」ボタンが表示され、押すと議題ページへ移動する。
3. トップページの次回予定でも、議題のある回は同様にボタンから議題ページへ移動できる。
4. 議題ページに、会議のタイトル・開催日時・開催場所・トピックと、改行を保持した議題の本文が表示される。URL を直接開いても同じ内容が表示される。
5. 議題が未入力の回には「議題」ボタンが表示されない。議題を空にして保存すると未設定に戻る。未入力の回の議題ページを直接開くと未登録の旨が表示され、存在しない回では 404 になる。
6. 議題本文に含まれる HTML タグは解釈されず、文字列として表示される。
7. 議題以外の既存項目(トピック・開催場所・会議URL 等)の保存と表示に変化がない。議題列の追加前から存在する回も正常に表示される。
8. `npm test` と `npm run check` が通る。
9. 見た目についてユーザーの確認を得ている(ユーザー実施)。
10. 本番 D1 への列追加後、本番環境で議題の保存と表示ができる(実環境・ユーザー実施)。

## 仕様書反映

スケジュール機能の恒久仕様書が存在しないため、`docs/requirements-schedule.md` を最小限の内容で新規作成する。

### 追加: スケジュールの項目

- 開催日・開催時間・タイトル(必須)、トピック・開催場所・会議URL・議題(任意)。

### 追加: 議題

- 入力・保存・議題ページ・導線・未入力時の扱い(確定要件のとおり)。
