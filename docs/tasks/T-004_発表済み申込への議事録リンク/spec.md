# 発表済み申込への議事録リンク

## 目的・背景

発表募集ページから該当回の議事録へたどる導線がない。speaker_applications テーブルには議事録・開催日との関連カラムが存在せず、自動対応付けはできないため、紐付けデータの追加と管理手段が必要。

## 確定要件

- speaker_applications に議事録紐付けカラム minutes_slug(NULL 許容)を追加する。
- 管理画面の発表募集管理ページ(/admin/speakers)で、既存のステータスドロップダウンの右に議事録選択ドロップダウンを追加する。選択肢は議事録一覧(未選択=紐付けなし も選択可)とし、発表が終わった際に管理者が手動で設定する(2026-08-27 ユーザー決定)。
- 発表募集ページ(/speakers)の申込カードに、minutes_slug が設定されている場合のみ該当議事録詳細へのリンクを表示する。未設定のカードには表示しない。
- 本番 D1 へのカラム追加(マイグレーション)はユーザーが実行する(本番変更の運用方針に従い、エージェントはコマンド提示まで)。

## 受入条件

- 管理画面で任意の申込に議事録を選択して保存すると、発表募集ページの該当カードに議事録詳細へのリンクが表示され、遷移できる。
- 管理画面で紐付けを「未選択」に戻すと、カードのリンクが消える。
- 紐付けのない既存申込の表示・編集・取り下げが従来どおり機能する(スキーマ変更の後方互換)。

## 検証方法

- 型チェック・ビルド: `npm run check`(エージェント実施)
- 単体テスト: 紐付け更新 API のテストを追加し `npm test`(エージェント実施)
- ローカルブラウザ確認: `npm run dev` + モックログインで管理画面の設定と公開側の表示を確認(エージェント実施)
- 本番 D1 マイグレーションの適用と本番画面での確認(実環境・ユーザー実施)
