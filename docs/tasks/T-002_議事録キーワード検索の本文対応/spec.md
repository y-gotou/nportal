# 議事録キーワード検索の本文対応

## 目的・背景

議事録一覧のキーワード検索は title・topics のみを対象としたクライアント側フィルタであり、本文(content_md)にのみ含まれる語(例: 第29回の「Jujutsu」)がヒットしない。一覧 API が本文を返さないため、クライアント側の修正では対応できず、サーバ側での検索が必要。

## 確定要件

- 検索の絞り込みをサーバ側で行う。検索対象は title・topics・content_md の3フィールドとする。
- 検索方式は部分一致(SQL LIKE)。英字の大文字小文字は区別しない(ASCII 範囲)。
- 検索方式の選定経緯: FTS5 全文検索・一覧 API へ本文同梱の各案と比較し、現行データ規模と実装の単純さからサーバ側 LIKE 検索を採用(2026-08-27 ユーザー決定)。
- キーワード未入力時は従来どおり全件を日付降順で表示する。
- 該当なしの場合は従来どおり「該当する議事録が見つかりません。」を表示する。

## 受入条件

- 本文にのみ含まれるキーワードで検索すると、該当議事録が一覧に表示される。
- タイトルまたはトピックに含まれるキーワードでの検索が従来どおり機能する。
- 英字キーワードの大文字小文字の違いを無視して一致する。
- 該当がない場合は「該当する議事録が見つかりません。」が表示される。

## 検証方法

- 型チェック・ビルド: `npm run check`(エージェント実施)
- 単体テスト: 検索ロジックのテストを追加し `npm test`(エージェント実施)
- ローカルブラウザ確認: `npm run dev` + モックログインで検索動作を確認(エージェント実施)
