# グローバルナビゲーションの折り返し解消

## 目的・背景

グローバルナビゲーションは、画面幅によって各項目とロゴの文字が2行に折り返し、ヘッダーの高さが 73px から最大 109px に増える。T-019 の検証中に見つかった、変更前からの挙動である。計測結果は次のとおり。

- 768〜936px: 横並びのナビを表示する幅(768px 以上)に対し、9項目が1行に収まるには約 940px が必要なため折り返す。
- 1024〜1060px: この幅からメールアドレスがヘッダーに表示され、ナビに使える幅が減るため折り返す。
- メールアドレスが 34 文字以上の利用者は、1024px 以上のすべての幅で折り返す(ヘッダーの内側の幅は 1152px で頭打ちになるため)。

確定要件:
- 横並びのナビと利用者欄(アイコン)を表示する幅を、768px 以上から 1024px 以上へ引き上げる。1023px 以下では、現在スマートフォンで使っているメニューボタンとメニューを表示する。
- ヘッダーのメールアドレスは、1024px 以上から 1280px 以上での表示へ引き上げる。長い場合は末尾を省略する。
- ナビの項目とロゴには、折り返さない指定を付ける。

対象外: メールアドレスをヘッダーに表示しない案(比較のうえ不採用)、ナビの項目の余白・文字サイズの変更、項目をまとめるメニューの新設、利用者メニューとモバイルメニューの内容の変更。

## 受入条件
- 画面幅 360〜1400px のどの幅でも、ナビの項目とロゴが折り返さず、ヘッダーの外へはみ出さない。メールアドレスが 34 文字の利用者でも同様である。
- 1024px 以上では横並びのナビが、1023px 以下ではメニューボタンが表示され、メニューから各ページへ移動できる。メールアドレスは 1280px 以上で表示され、長い場合は末尾が省略される。
- 利用者メニュー(アイコンを押して開くメニュー)の内容と、その中のメールアドレスの表示は変わらない。
