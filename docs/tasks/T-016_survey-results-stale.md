# 回答送信後の結果ページに自分の回答が反映されない不具合

## 目的・背景

アンケートの回答を投稿・更新した後、完了表示(「回答ありがとうございました」「回答を更新しました」)の「結果を見る」から結果ページへ遷移すると、送信した回答が集計・自分の回答表示に反映されない。ページを再読み込みすると反映される。

原因: 回答ページと結果ページは共通の `useSurveyDetail` から同一の `useFetch("/api/survey", { query: { surveyId } })` を呼ぶため、同じ asyncData キーを共有する。クライアント遷移では遷移先の setup が遷移元のアンマウントより先に実行されるため、回答ページで取得済み(status: success)のデータが残っており、Nuxt 4 はこの場合に再取得しない。結果として回答送信前のデータで結果ページが描画される。

## 受入条件
- 回答の新規投稿後に完了表示の「結果を見る」から遷移すると、回答者数・集計・自分の回答表示に送信内容が反映される。
- 回答の更新後に同様に遷移すると、更新後の内容が反映される。
- 回答ページ・結果ページの直接表示(SSR)および既存の表示は変わらない。

## 仕様書反映

なし(仕様どおりの動作に戻す修正のため)。

### 時系列
- 2026-09-18: ユーザー報告により起票。原因を Nuxt 4.4.2 の `useAsyncData` 実装(取得済みキーは再取得しない)から特定。
- 2026-09-18: G1 承認。`useSurveyDetail` の `useFetch` に明示キーを付け、`SurveyForm` の送信成功時に `clearNuxtData` で当該キーを破棄する修正を実装。完了表示は取得済みのオブジェクトで描画しているため影響しない(`refreshNuxtData` は新規投稿時に完了表示が回答済み表示へ切り替わるため不採用)。追加テストは修正前に失敗することを確認。`npm test`(193 件)・`npm run check` ともに成功。ローカルで新規投稿・更新の双方について「結果を見る」遷移後に送信内容が反映されることを確認し、修正を外した状態では更新前の回答が表示されること(不具合の再現)も確認した。なお修正の退避・復元直後の HMR 状態では一度反映されず、dev サーバー再起動後は正常に反映された。
