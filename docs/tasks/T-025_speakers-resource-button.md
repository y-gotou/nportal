# 発表募集の「資料を開く」を青い主ボタンに変更

## 目的・背景

資料を開く操作は、ホーム「最近の資料」では青い主ボタン、資料一覧では青いタイトルリンクで表示している。発表募集のカードの「資料を開く」だけが白いボタンで、同じ操作の見た目が揃っていない。発表募集でも青い主ボタンにして揃える。

青い主ボタンは枠線が無く、高さが 40px である。枠線のあるボタン(42px)と並ぶと 2px 低くなる。発表募集のカードのボタン群は縦中央寄せのため、色を変えるだけでは「議事録を見る」「編集」「取り下げ」と高さが揃わない(T-023 で既存の課題として記録した差)。

確定要件:

- 発表募集のカードの「資料を開く」を、青い主ボタン(共通の `primaryButtonClass`)にする。リンク先・開き方・表示条件は変えない。
- 青い主ボタンの共通の指定に透明の枠線を加え、高さを枠線のあるボタンと同じ 42px にする。一般画面の青い主ボタンすべてに適用される(ホーム、アンケート、スケジュール、資料、発表募集、課題、不具合・要望)。

対象外: 管理画面の青いボタン(共通の指定を使っていない)、ログイン画面のボタン、「議事録を見る」など他のボタンの配色。

## 受入条件
- 発表募集のカードの「資料を開く」が、ホーム「最近の資料」の「資料を開く」と同じ青い主ボタンで表示される。リンク先・開き方・表示条件は変わらない。
- 「資料を開く」の高さが、同じカードの「議事録を見る」「編集」「取り下げ」と一致する。「資料を開く」だけが表示されるカードでも同じ高さになる。
- 一般画面の他の青い主ボタンは、高さが 42px になる以外に表示が変わらない(折り返し・位置ずれが無い)。

## 仕様書反映

`docs/requirements-speakers.md`「応募カードの表示」のボタン群の項を変更する。

- 変更: 「資料を開く」は青い主ボタンとし、他のボタンと同じ大きさとする旨を追記する。
