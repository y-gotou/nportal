# 議事録機能 要件定義書

- 作成日: 2026-08-27
- 更新日: 2026-08-27(T-002 検索の本文対応・T-003 前後ナビゲーションを反映)
- ステータス: 実装完了・運用中

本書は T-002・T-003 の起票に伴い新規作成した最小限の As-Built 仕様書。既存実装の全容ではなく、一覧・詳細・検索・前後ナビゲーションの仕様を記載する。

## 1. 背景・目的

社内 AI 勉強会の議事録を N Portal 上で蓄積・閲覧できるようにし、過去の回の内容を後から振り返れるようにする。

## 2. 機能概要

- 議事録一覧ページ(`/minutes`)で全議事録を開催日の降順に表示し、キーワード検索で絞り込める(§3)。
- 議事録詳細ページ(`/minutes/{slug}`)で本文(Markdown を HTML 化したもの)・開催日・発表者・トピック・関連資料を表示する。slug は開催日(`YYYY-MM-DD`)そのもの。
- 詳細ページには「一覧へ戻る」、同日開催のチャットがある場合の「チャットを見る」、前後の回への移動(§4)の導線を置く。
- 議事録の作成・編集・削除は管理画面(`/admin/minutes`)で行う。

## 3. キーワード検索

- 絞り込みはサーバ側で行う(`GET /api/minutes?q=キーワード`)。
- 検索対象は タイトル・トピック・本文(content_md)の3フィールド。
- 部分一致(SQL LIKE)。`%`・`_`・`\` はエスケープし、リテラルとして扱う。英字の大文字小文字は区別しない(ASCII 範囲)。
- キーワード未入力時は全件を日付降順で返す。該当なしの場合は「該当する議事録が見つかりません。」を表示する。
- 検索欄への入力は約300msのデバウンス後に URL クエリ `q` へ反映され、URL の共有・再訪で検索状態を再現できる。

## 4. 前後ナビゲーション

- 詳細 API が日付順から前(過去方向)・次(未来方向)の議事録(slug・title・date)を導出して返す。
- 詳細ページの上部ボタン列右端と、ページ末尾(関連資料の下)に「前の議事録」「次の議事録」ボタンを表示する。ボタン名称のみで日付・タイトルは併記しない。
- 前または次が存在しない場合(最古・最新)、該当ボタンは表示しない。
