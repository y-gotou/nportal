# 課題機能 要件定義書

- 作成日: 2026-10-02
- 更新日: 2026-10-02(T-019 課題機能の追加、T-020 ナビの表示切り替えの幅を反映)
- ステータス: 実装完了・運用中

本書は T-019 の起票に伴い新規作成した As-Built 仕様書。課題機能の仕様と、グローバルナビゲーションの項目を記載する。

## 1. 背景・目的

社内 AI 勉強会で出た宿題や、運営の対応事項を、誰が・いつまでに行うかとあわせて一覧で共有する。完了したかどうかを全利用者が確認できるようにする。会議中に画面共有しながら、その場で課題を登録・完了にする使い方を想定する。

## 2. 機能概要

- 課題ページ(`/todos`)で、課題の一覧を表形式で表示する(§4)。
- 管理者は、課題ページ上で課題の追加・編集・削除・完了の切り替えを行う(§5)。管理画面には課題の管理ページを設けない。
- 議事録の詳細ページに、その議事録に紐付く課題を表示する(§6)。
- 会議の宿題と運営の対応事項は区別せず、一つの一覧で管理する。

## 3. 課題の項目

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| 件名 | 必須 | 1行のテキスト。200 文字まで。前後の空白は除去して保存する |
| 担当 | 任意 | 自由入力のテキスト。50 文字まで。利用者のアカウントとは対応付けない |
| 期限 | 任意 | 日付 |
| 議事録 | 任意 | 登録済みの議事録から1件を選ぶ。選択肢は開催日の新しい順 |
| 状態 | — | 未完了・完了の2段階。完了にした日時を記録する(画面には表示しない) |

- 件名に書かれた HTML は文字列として表示する。
- 議事録は、登録時は空欄にしておき、議事録の作成後に編集で設定できる。
- 議事録を削除した場合、その議事録に紐付いていた課題は残し、紐付けのみ解除する。

## 4. 課題ページ

- ページの見出しは「課題一覧」とする。ブラウザのタブ名とナビのラベルは「課題」とする。
- 列は、完了のチェックボックス・課題・担当・期限・議事録。各行の内容は上下中央に揃える。
- 議事録の列には紐付けた議事録のタイトルを表示し、その議事録の詳細ページへリンクする。
- 期限を過ぎた未完了の課題は、期限を赤字で表示する。「超過」等の文字は付けない。期限の当日は超過としない。判定は日本時間の日付で行う。
- 並び順は、未完了が登録の新しい順、完了済みが完了にした日時の新しい順。
- 通常は未完了のみを表示する。表の最下段の「完了済み(n件)」を押すと、完了済みの課題を展開して表示する。完了済みの件名には取り消し線を付ける。完了済みが0件のときは「完了済み」の行を表示しない。
- 未完了が0件で完了済みがある場合は、未完了の課題が無い旨を表に表示する。未完了・完了済みとも0件のときは、表を表示せず、課題が登録されていない旨を表示する。
- 狭い画面では、表を枠内の横スクロールで表示する。

## 5. 管理者の操作

登録・編集・削除・完了の切り替えができるのは管理者のみ。閲覧は全利用者ができる。管理者が課題ページを開いたときだけ、次の操作欄を表示する。

- **追加**: 一覧の上に追加欄(件名・担当・期限・議事録・追加ボタン)を常時表示する。
- **完了の切り替え**: 行のチェックボックスで切り替える。完了にした課題は「完了済み」側へ移り、チェックを外すと未完了へ戻る。完了済みの課題をもう一度完了にしても、完了にした日時は変えない。
- **編集**: 行の右端の鉛筆アイコンを押すと、その行が入力欄に切り替わる。チェックのアイコンまたは Enter キーで保存し、×のアイコンまたは Esc キーで保存せずに閉じる。日本語入力の変換中の Enter キーと Esc キーには反応しない。
- **削除**: 行の右端のゴミ箱アイコンを押し、確認のうえ削除する。削除した課題は元に戻せない。
- 保存・削除に失敗した場合は、表の上にエラー文を表示する。編集中の入力欄は開いたまま残す。

管理者以外には、追加欄・編集と削除のアイコンを表示しない。チェックボックスは操作できない状態で表示する。管理者以外からの登録・編集・削除・完了の切り替えの要求は拒否する。

## 6. 議事録ページへの表示

- 議事録の詳細ページの本文の下(「関連資料」の上)に、その議事録に紐付く課題の一覧を表のみで表示する。見出し・説明文・課題ページへのリンクは置かない。本文との間隔は、課題ページの追加欄と表の間隔に揃える。
- 列は、完了のチェックボックス(操作不可)・課題・担当・期限。
- 未完了を先に、完了済みを後に並べる。完了済みも折りたたまずに、取り消し線を付けて表示する。
- 管理者を含め、議事録ページでは操作できない。
- 紐付く課題が無い議事録では、この欄を表示しない。

## 7. グローバルナビゲーション

- 項目と並びは、ホーム・議事録・スケジュール・アンケート・課題・資料・発表・ニュース・BBS。
- 「資料」は資料共有ページ、「発表」は発表募集ページを指す。短縮しているのはナビのラベルのみで、ブラウザのタブ名では「資料共有」「発表募集」を用いる。ページの見出しは「資料一覧」「発表募集」、管理画面は「資料」「発表募集」とする。
- 横並びのナビと利用者欄(アイコン)は、画面幅 1024px 以上で表示する。1023px 以下では、メニューボタンと、そこから開くメニューを表示する。9項目の横並びには約 940px が必要なため、768px から横並びにすると文字が折り返す。
- ナビの項目とロゴは折り返さない。
- ヘッダーのメールアドレスは、画面幅 1280px 以上で表示する。長い場合は末尾を省略する。省略されていないメールアドレスは、アイコンを押して開くメニュー内で確認できる。

### 対象外

- 3段階の状態(未着手・対応中・完了)、完了時の対応メモ、複数行の詳細欄
- 会議回(スケジュール)との紐付け、議題ページへの表示
- アンケート回答・不具合要望報告からの起票
- トップページへの表示
- 管理者以外による登録・編集・完了(担当者本人による完了を含む)
- 担当と利用者アカウントの対応付け、「自分の課題」の絞り込み
- 絞り込み・検索・並び順の切り替え
- 期限の通知
- 議事録ページでの課題の操作
- 管理画面の課題管理ページ
